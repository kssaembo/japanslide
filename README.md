# 한글학교 AI 연수 웹 프레젠테이션

20장·60분. 별도 서버, 로그인, 환경변수 없이 실행합니다. AI 선생님 투표 서비스는 외부 링크로 연결됩니다.

## 실행·배포

```sh
npm ci
npm run dev
npm test
npm run build
```

GitHub에 소스를 올리고 Vercel에서 가져옵니다. Framework: Vite, Build: `npm run build`, Output: `dist`. 기존 프로젝트라면 변경 파일을 올린 뒤 재배포합니다. 환경변수는 필요하지 않습니다. 이 수정은 외부 투표 서비스의 데이터베이스를 변경하지 않습니다.

## 보기

- `/present/day1`: PC·프로젝터 발표. 방향키 이동, Space 내용 공개, 전체 화면 버튼.
- `/read/day1`: 모바일 한 장씩 보기. 하단 화살표 또는 화면 오른쪽 20%의 빈 영역을 눌러 다음 장으로 이동합니다. 긴 한 장은 내부 스크롤이 가능합니다.
- `/edit/day1`: 브라우저에서 직접 편집.
- `/notes/day1`: 같은 브라우저에 저장한 발표자 노트.

카드를 누르면 상세 설명과 출처가 열립니다. 그림 확대, 수준 선택, 오류 퀴즈, 예시 게임은 참가자별로 독립적으로 작동합니다. 2번 슬라이드의 AI 캐릭터를 누르면 면접 서비스로 이동합니다. `/read/day1#slide-3`처럼 특정 장으로 바로 이동할 수 있습니다.

## 내용 수정 후 전체 공개

1. 자료 편집에서 제목·본문·카드·이미지를 바꾸고 저장합니다.
2. ‘게시’는 **이 브라우저에만** 적용합니다. 다른 사람의 화면이나 배포 주소는 바뀌지 않습니다.
3. ‘JSON 내보내기’를 누릅니다. 업로드한 이미지는 JSON에 포함됩니다.
4. 다운로드한 `day1.json`으로 소스의 `src/content/day1.json`을 교체하고 GitHub에 올려 Vercel에서 재배포합니다.
5. 다른 기기에서 새로고침해 확인합니다. 발표 직전 오래 열어둔 창은 닫고 새로 엽니다.

편집은 로그인 없이 가능하지만 해당 브라우저 데이터만 바꿉니다. 공개 사이트의 원본을 바꾸려면 소스 재배포가 필요합니다. 브라우저 데이터를 삭제하기 전에 JSON을 내보내세요.

이미지 업로드는 10MB 이하 JPG·PNG·WebP입니다. 영상은 HTTPS 직접 파일 주소 또는 시연 링크로 등록합니다. 발표자 노트는 공개 JSON에 포함되지 않습니다. 노트까지 보관하려면 `seed/day1-private.json` 형식의 비공개 패키지를 별도로 관리하세요. ‘초기 강의 가져오기’에서 해당 파일을 불러오면 노트를 볼 수 있습니다.

## 오프라인·현장 점검

배포 주소에 미리 접속하고 ‘오프라인 준비’를 누른 뒤, 인터넷을 끊어 새로고침과 이동을 시험합니다. 기본 그림과 앱은 빌드별로 캐시됩니다. 외부 투표·AI 서비스·외부 영상에는 인터넷이 필요합니다. 외부 시연 대신 ‘예시 보기’를 사용하세요.

슬라이드별 시각 자료는 벡터 일러스트입니다. 추석 시연에는 기존 AI 생성 삽화도 포함합니다. 실제 AI 생성 영상은 기본 제공하지 않습니다.
