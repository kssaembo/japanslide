# 내용 카드 이미지

편집 → 내용 → 내용 카드에서 카드별 이미지 업로드/교체 또는 직접 이미지 HTTPS 주소를 입력합니다. 제목·설명과 함께 이미지가 표시되며 카드 클릭 시 이미지와 설명을 크게 볼 수 있습니다. 팝업 이미지를 한 번 더 클릭하면 이미지 단독으로 확대됩니다. 제목과 설명을 비워 이미지 중심 카드로 사용할 수도 있습니다.

카드별 이미지 설명·확대·크롭 위치·제거를 지원합니다. JPG·PNG·WebP 10MB 이하입니다.

## 저장 위치

- 편집 화면에서 업로드한 이미지·영상 원본: 접속한 기기의 해당 브라우저 IndexedDB(ha-local-media).
- 편집 내용과 현재 브라우저 게시본: localStorage.
- 이 상태에서 저장·게시해도 다른 기기로 자동 전송되지 않습니다. 사이트 데이터 삭제 시 로컬 저장본이 사라질 수 있습니다.
- JSON 내보내기는 슬라이드·이미지 전용·내용 카드·시연 자료의 로컬 파일을 데이터로 포함합니다. src/content/day1.json에 적용하고 다시 배포하면 다른 기기에서도 볼 수 있습니다.
- 기존 HTTPS 주소로 등록한 자료는 그 주소의 서버에서 불러옵니다. public/assets에 포함해 배포한 자료는 배포된 웹서버에서 불러옵니다.

다른 기기 공개 순서: 저장 → JSON 내보내기 → src/content/day1.json 교체 → GitHub 업로드 → Vercel 재배포. 여러 이미지나 영상 때문에 JSON 용량이 커지면 public/assets에 파일을 넣고 그 파일의 HTTPS 주소로 연결하는 방법을 권장합니다. Supabase는 사용하지 않습니다.
