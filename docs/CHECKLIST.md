# 출국·강의 전 점검

- [ ] 새 Vercel 프로젝트 URL로 PC와 스마트폰에서 접속한다.
- [ ] 환경변수 2개를 등록한 뒤 Redeploy한다.
- [ ] ha_* SQL을 실행하고 관리자 UUID를 ha_admins에 등록한다.
- [ ] 강사 로그인 → 초기 패키지 가져오기 → 저장 → 게시한다.
- [ ] 다른 브라우저의 /read/day1에서 수정된 제목과 게시 버전을 확인한다.
- [ ] 비관리자 계정과 로그인 없는 창에서 수정/노트 조회가 막히는지 확인한다.
- [ ] 이미지 업로드·교체·확대·크롭·저장·게시를 확인한다.
- [ ] 영상 MP4/WebM 재생과 파일 누락 시 대체 설명을 확인한다.
- [ ] 수정 이력 복원, 순서 변경, 복제, 삭제, 복구본 안내를 확인한다.
- [ ] 서로 다른 편집 창에서 동시에 저장해 덮어쓰기 방지를 확인한다.
- [ ] 기존 투표 서비스의 실제 공개 URL을 시연 탭에 등록한다.
- [ ] 추석 입문·초급·중급 선택, 오류 찾기 퀴즈, 웹게임을 눌러 본다.
- [ ] 노트북과 프로젝터를 화면 확장으로 설정하고 노트 창을 분리한다.
- [ ] 16:9 전체 화면에서 20장 글씨와 긴 자료의 스크롤·확대를 확인한다.
- [ ] iPhone Safari와 Android Chrome에서 세로 읽기·이미지 확대를 확인한다.
- [ ] 최신 버전 확인 → 오프라인 준비 → 네트워크 끊기 → 새로고침·슬라이드 이동을 실제 시험한다.
- [ ] 외부 시연이 실패하면 사전 제작 예시로 진행한다.
- [ ] 서비스 기능·연령·기관 지침을 발표일 기준 다시 확인한다.
- [ ] 시연 영상은 직접 업로드한다. 기본 패키지에는 실제 AI 생성 영상이 없다.
