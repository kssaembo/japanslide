# 슬라이드 참여 링크 변경

2번 슬라이드의 버튼과 캐릭터, 면접 시연 링크를 다음 주소로 연결했습니다.

https://japan-chi-hazel.vercel.app/vote

AI 서비스의 Vercel 환경변수 VITE_EVENT_CODE에는 기존 고정방 식별자가 설정되어 있어야 합니다. 설정 후 AI 서비스를 재배포하세요. Supabase SQL 변경은 필요 없습니다.

이전 브라우저 저장본이나 가져온 JSON에서 면접 서비스 메인 주소를 사용하는 경우에도 해당 링크만 참여 주소로 전환합니다. 별도로 등록한 다른 주소는 유지합니다.

updated-day1.json은 최근 전달한 19장 편집본에서 면접 링크 하나만 바꾼 파일입니다. 기존 본문과 이미지 데이터는 유지했습니다. 배포 콘텐츠로 사용하려면 이 파일을 src/content/day1.json에 덮어쓴 후 배포하세요. 이후 테스트에 있는 초기 콘텐츠 20장·60분 조건은 편집본에 맞춰 조정해야 합니다.

브라우저에 아직 내보내지 않은 새 수정 사항이 있다면 기존 편집기를 그대로 사용하세요. 재배포한 코드는 기존 저장본의 메인 링크를 자동으로 바꾸며 나머지 편집 내용은 유지합니다.
