# 이미지 + URL 유형

편집 → 내용 → 슬라이드 유형 → 이미지 + URL을 선택합니다.

- URL 버튼 제목: 화면에 표시할 버튼 문구.
- 이동할 URL: HTTPS 주소.
- 이미지·영상 → 업로드/교체: 표시할 이미지 1장(JPG·PNG·WebP).

이미지와 버튼만 표시하며 제목·본문·카드는 숨깁니다. 이미지 클릭은 확대, 버튼 클릭은 해당 URL로 이동합니다. 기존 내용은 삭제하지 않습니다. 저장·게시와 JSON 내보내기에도 링크 정보가 포함됩니다.

버튼은 같은 탭에서 열립니다. 일반적인 외부 링크 이동 후 브라우저 뒤로가기를 누르면 기존 슬라이드로 돌아옵니다. 모바일은 슬라이드 번호를 주소 해시와 세션에, 발표 모드는 같은 탭의 세션에 저장합니다. 외부 사이트의 자체 이동이나 방문기록 변경 때문에 뒤로가기를 여러 번 눌러야 할 수 있습니다. 외부 사이트 안에 ‘원래 슬라이드로 돌아가기’ 버튼을 자동으로 추가하지는 않습니다.

다른 기기에서도 같은 자료가 보이게 하려면 JSON을 내보내 배포 콘텐츠에 적용한 뒤 재배포하세요. 업로드 이미지의 저장 방식은 기존과 같습니다.
