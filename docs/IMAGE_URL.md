# 이미지 + URL · 최대 3개

편집 → 내용 → 슬라이드 유형 → 이미지 + URL → 항목 추가를 누릅니다.

각 항목 안에서 이미지 업로드/교체, 이미지 타이틀, 크롭/확대, 버튼 제목, 이동할 HTTPS URL을 함께 설정합니다. 이미지 주소를 직접 입력할 수도 있습니다. 최대 3개이며 좌우 이동·항목 삭제를 지원합니다. 이미지 제거는 버튼을 유지하며 항목 삭제는 이미지와 버튼을 함께 삭제합니다.

발표 화면: 1개 중앙, 2개 좌우, 3개 좌·중앙·우. 모바일은 항목별로 세로 배치합니다. 이미지 클릭 시 확대되며 외부 링크 버튼은 새 탭에서 열립니다. 원래 발표 탭으로 돌아오면 기존 슬라이드가 유지됩니다.

리모컨 다음 입력은 각 이미지를 순서대로 확대하고 마지막 이미지 뒤에 다음 슬라이드로 이동합니다. 외부 URL을 자동으로 열지는 않습니다.

기존 이미지 1장·버튼 1개 자료는 새 항목 구조로 자동 변환합니다. 이미지 타이틀과 버튼 제목·주소를 유지합니다. 저장·게시, JSON 가져오기·내보내기, Supabase 미디어 업로드, 오프라인 자료 저장에 반영합니다. 새 SQL 적용은 필요 없습니다.
