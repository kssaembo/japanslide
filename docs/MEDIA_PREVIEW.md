# 우측 이미지·동영상

편집 → 슬라이드 선택 → 내용 → 이미지·영상에서 업로드하거나 직접 파일의 HTTPS 주소를 입력하세요. 이미지 크롭·확대는 미리보기에만 적용하며 팝업은 원본 비율로 표시합니다.

자료가 없으면 기존 주제 아이콘을 표시합니다. 아이콘 팝업은 그림만 표시하며 슬라이드 텍스트를 반복하지 않습니다. 내용 카드의 설명 팝업은 그대로 유지합니다.

이미지 클릭: 큰 화면으로 표시. 영상 클릭: 팝업에서 재생·일시정지·탐색·음량 조절. 닫기·바깥 클릭·ESC로 닫습니다. 모바일에서는 본문 메시지 아래에 미리보기를 배치합니다.

JPG·PNG·WebP는 10MB 이하, MP4·WebM은 50MB 이하로 업로드할 수 있습니다. 영상은 MP4(H.264/AAC)를 권장합니다. 일반 YouTube 페이지 주소 대신 직접 재생 가능한 파일 주소를 사용하세요.

업로드는 현재 브라우저에 저장됩니다. 다른 기기에 공개하려면 저장 → JSON 내보내기 → 소스의 src/content/day1.json 교체 → 재배포가 필요합니다. 영상 포함 JSON은 커질 수 있으므로 큰 영상은 public 폴더에 넣고 직접 파일 HTTPS 주소로 연결하는 방법을 권장합니다. 기존 Supabase 미사용 구조를 유지합니다.
