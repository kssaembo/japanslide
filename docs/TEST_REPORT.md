# 검증 결과

2026-10-10 / 이 개발환경에서 실행

프론트엔드·오프라인 자동 테스트 **13개 통과**, PostgreSQL 검증 **8개 묶음 통과**, 프로덕션 빌드 통과.

## 자동 검증

- React·TypeScript 프로덕션 빌드
- 20장 / 60분 / 시연 자료 8종 구조 검증
- 공개 데이터에서 상세 노트·알 수 없는 비공개 필드 제거
- 실행 가능한 URL 거부, React 텍스트 출력의 XSS 경계
- 로컬 편집 → 저장 → 게시 분리
- 슬라이드 복제·삭제·순서 변경과 수정 이력 복원
- 추석 수준 선택, 오류 찾기 퀴즈, 클릭 가능한 어휘 게임
- AI 삽화 선택 및 이미지 오류 시 본문 유지
- Service Worker 오프라인 네비게이션/공개 미디어 캐시, 인증·DB 요청 제외
- 정적 배포 산출물에 private seed 패키지가 포함되지 않음

## PostgreSQL/PGlite SQL 검증

- 마이그레이션 재실행
- 비관리자 저장 거부
- 익명 및 비관리자의 임시 저장본·노트·이력 접근 차단
- 공개 자료만 익명 조회 가능
- 수정 번호 충돌 시 저장·게시 거부
- 임시 저장과 게시본 분리, 노트도 게시 시점 스냅샷 유지
- 저장 이력 기록 및 이전 내용의 새 수정본 저장
- 비공개 필드·위험 주소의 게시 데이터 유입 차단
- 게시된 미디어만 Storage 조회 정책 통과

## 아직 현장 검증하지 못한 항목

실제 Supabase URL/공개 키가 제공되지 않아, 실제 Auth 로그인·Storage 업로드·게시 후 다른 기기 반영은 검증하지 않았습니다. SQL과 해당 연동 코드 및 설정 절차를 제공했습니다. PGlite는 실제 Supabase 서비스·API를 대체하지 않습니다.

이 환경에서 지원되는 브라우저 QA 도구가 없어 실제 화면 렌더링, 16:9 글씨 크기·겹침, iPhone Safari/Android Chrome, 브라우저 파일 디코딩·영상 재생, 전체 화면·두 창 동기화 및 실제 오프라인 새로고침은 검증하지 않았습니다. DOM·Service Worker 코드 검증만 수행했습니다. 현장 체크리스트에서 확인하세요.

실제 AI 생성 영상은 제작하지 않았습니다. AI 생성 삽화 1개, 영상 제작안·텍스트 대체 예시, 업로드 기능을 제공합니다. 실제 투표는 기존 외부 서비스가 담당하며 새 슬라이드 서비스는 투표 데이터를 변경하지 않습니다.
