# 슬라이드 유형 선택

편집 → 슬라이드 선택 → 내용 → 슬라이드 유형에서 선택합니다.

표지·핵심 문장·내용 카드·단계/순서·비교·사례/미디어·인터랙티브·마무리·이미지 전용을 제공합니다. 인터랙티브 유형 선택만으로 퀴즈가 자동 생성되는 것은 아닙니다. 기존 인터랙티브 데이터가 있는 슬라이드를 복제하여 내용을 수정할 수 있습니다.

## 이미지 전용

- 이미지 1장: 중앙에 크게 표시.
- 2장: 왼쪽·오른쪽.
- 3장: 왼쪽·가운데·오른쪽.
- 제목·본문·카드·출처는 화면에 표시하지 않습니다. 내부 제목은 목차와 편집 목록에서 사용합니다.
- ‘이미지 추가’로 업로드하거나 ‘이미지 주소로 추가’를 누르고 HTTPS 직접 이미지 주소를 입력하세요.
- 이미지 교체·설명·확대·크롭 위치·삭제·좌우 순서를 수정할 수 있습니다.
- 이미지 클릭 시 원본 비율의 큰 팝업으로 열립니다. ESC·닫기·바깥 클릭으로 복귀합니다.
- 다른 유형으로 바꿔도 기존 텍스트와 이미지 데이터는 보존됩니다.
- JPG·PNG·WebP 10MB 이하 이미지, 최대 3장입니다.

저장 → 게시하면 현재 브라우저에 적용됩니다. 다른 기기에 공개하려면 JSON 내보내기 후 배포 콘텐츠를 교체하여 재배포하세요. 기존 19장 편집본을 유지하려면 JSON을 가져오거나 이미 저장된 편집본에서 작업하세요.
